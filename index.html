🔑 Hướng dẫn lấy Google OAuth Client ID

1Tạo Google Cloud Project
Vào console.cloud.google.com → New Project → đặt tên brief-builder → Create.
2Bật Google Drive API
Menu trái → APIs & Services → Library → Tìm Google Drive API → Enable.
3Tạo OAuth Consent Screen
APIs & Services → OAuth consent screen → Chọn External → Fill tên app → Add scope: https://www.googleapis.com/auth/drive.file → Save → Publish app (hoặc thêm test user là email của bạn).
4Tạo OAuth Client ID
Credentials → Create Credentials → OAuth client ID → Application type: Web application

Thêm Authorized JavaScript origins:
https://kristensjd.github.io

Thêm Authorized redirect URIs:
https://kristensjd.github.io

→ Create → Copy Client ID (dạng xxx.apps.googleusercontent.com)
5Lấy Drive Folder ID (optional)
Mở folder muốn lưu trên Google Drive → xem URL:
drive.google.com/drive/folders/[FOLDER_ID]
Copy phần FOLDER_ID dán vào ô Folder ID bên trên.
✅ Sau khi điền Client ID → nhấn nút Drive trên thanh top → Google popup xin quyền → Allow → Kết nối thành công!

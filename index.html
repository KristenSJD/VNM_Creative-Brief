🔒 Apps Script URL (riêng tư)
Chưa push lần nào từ máy này
Hướng dẫn setup (1 lần duy nhất)
Bước 1: Tạo Google Sheet mới → copy ID từ URL
https://docs.google.com/spreadsheets/d/SPREADSHEET_ID/edit

Bước 2: Vào script.google.com → New project → paste toàn bộ code từ file brief-manager.gs

Bước 3: Trong file .gs, sửa dòng đầu:
const SPREADSHEET_ID = 'PASTE_ID_VỪA_COPY';
Bước 4: Chạy testAll() để kiểm tra (cần cấp quyền lần đầu)

Bước 5: Deploy → New deployment → Web app → Execute as: Me → Access: Anyone → Deploy → copy URL

Bước 6: Paste URL vào ô Apps Script URL bên trên → Test kết nối

Bước 7 (Admin): Điền đầy đủ settings → nhấn Push to Cloud → gửi link app cho team → xong! ✅
